# Upload your book examples to GitHub

Repository: https://github.com/nvanamal/-machine-learning-book-code
Author: Dr. Nagendrababu Vanamala

This package contains 102 complete Python scripts and 102 companion guides, organized by topic. The guides contain line-by-line explanations and the output recorded in the book. You do not need to copy any code by hand.

## Upload on a computer

1. Unzip this package.
2. Open your repository while signed in to GitHub.
3. Choose Add file, then Upload files.
4. Open upload_batch_1 on your computer. Drag its CONTENTS (examples, guides, README.md, requirements.txt, .gitignore and example_index.json) into the upload area. Do not drag the outer upload_batch_1 folder or the ZIP file.
5. Add a commit message such as "Add book code, batch 1", then commit the changes to main. Replacing the initial README.md with this complete README is intended.
6. Repeat with the CONTENTS of upload_batch_2, then upload_batch_3. These add different topic subfolders to the same examples/ and guides/ directories.
7. Open README.md in the repository. Check that the example links open. Tell me when all three batches are uploaded so I can verify every link and add the QR codes to your book.

The three batches contain 76, 72 and 60 files respectively. The folders inside each batch are necessary: they preserve the paths that the book's QR codes will use.
